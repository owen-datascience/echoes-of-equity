# Lesson 3 Mini Project - WAV to Mel-Spectrogram

This mini project goes with Lesson 3 of the Echoes of Equity course.

You will:
1. Load a WAV file (`demo_tone.wav`).
2. Compute its Mel-spectrogram using `librosa`.
3. Save the Mel-spectrogram as an image (`demo_tone_melspec.png`).

## Setup

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install librosa matplotlib
```

## Run

```bash
python src/make_melspec.py
```

After running, check the `data/` folder for the generated PNG image.
