# Lesson 2 Mini Project - Baseline Fairness Analysis

This mini project goes with Lesson 2 of the Echoes of Equity course.

## What you will do

1. Load a small synthetic voice-intent dataset.
2. Inspect label and ethnicity distributions.
3. Compute a simple majority-class baseline.
4. Measure accuracy and recall overall and per-ethnicity.
5. Observe any fairness gaps between groups.

## How to use

1. Create and activate a Python environment (3.9+ recommended).
2. Install dependencies:

   ```bash
   pip install pandas scikit-learn
   ```

3. Run the script:

   ```bash
   python src/analyze_fairness.py
   ```

4. Read the printed results and answer the reflection questions from Lesson 2.
